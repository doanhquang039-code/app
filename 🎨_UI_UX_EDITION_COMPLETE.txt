📡 API ENDPOINTS
═══════════════════════════════════════════════════════════════════════════════

DASHBOARD APIs:
  GET    /dashboard/advanced/:userId              - Get advanced dashboard data
  GET    /dashboard/advanced/:userId/realtime     - Get real-time stats

NOTIFICATION APIs:
  GET    /notifications/:userId                   - List user notifications
  GET    /notifications/:userId/unread-count      - Get unread count
  PATCH  /notifications/:notificationId/read      - Mark notification as read
  PATCH  /notifications/:userId/read-all          - Mark all as read
  DELETE /notifications/:notificationId           - Delete notification
  DELETE /notifications/:userId/clear-all         - Clear all notifications
  POST   /notifications                           - Create notification

SEARCH APIs:
  POST   /search/transactions/:userId             - Search transactions
  POST   /search/advanced/:userId                 - Advanced multi-entity search
  GET    /search/filter-options/:userId           - Get available filter options
